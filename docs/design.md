리듬 회피 게임 설계서
2026년 10월 15일 · @최서진
게임 개요
검은 화면의 5×5 격자 안에서, 노래의 비트에 맞춰 날아오는 장애물을 피해 곡 끝까지 살아남는 2D 리듬 회피 게임이에요. 목표는 부드러운 모션과 깔끔함이에요.
• 범위: 3명, 약 3주, 완성된 곡 1개
• 엔진: Unity 최신 LTS, Universal 2D 템플릿 (유니티는 처음)
• 디자인 원칙: 한 가지 색과 단순한 도형만 사용
• 작업 방식: 3명이 한 컴퓨터에 모여서 작업하므로 Git 공유는 필요 없음
• 제작 방식: Claude에게 한 단계씩 지시하고, 직접 실행해서 확인한 뒤 다음 단계로 넘어감 (아래 "단계별 제작 순서")
비주얼과 플레이어
화면은 검은 배경 위의 흰 선 격자 하나와 빛나는 빨간 하트 하나로 이루어져요.
• 배경: 검은색. 격자는 5×5, 흰 선으로만 그림 (칸을 채우지 않음)
• 하트 모양: 45도 기울인 정사각형을 2×2로 나눈 조각 중 위쪽 조각을 뺀 6면 도형. 왼쪽·오른쪽·아래 조각 3개로 이루어짐
• 하트 색: 빛나는 빨강 (Bloom 등 후처리로 표현)
• 하트 크기: 칸보다 조금 작게. 충돌 판정도 이 크기 기준
• 조작: WASD와 방향키. 키를 한 번 누르면 한 칸 이동. 격자 밖으로는 못 나감
• 이동 느낌: 목표 칸까지 남은 거리의 일정 비율씩 접근해서 부드럽게 움직임. 너무 느려 보이지 않도록 비율은 설정값으로 빼서 조절
• 잔상: 이동 중 지나간 자리에 하트 모양 복사본이 남았다가 빠르게 흐려짐
• 충돌: 이동 중(칸 사이)에도 하트의 실제 위치로 판정
체력과 피격 연출
목숨은 3개이고, 하트의 안쪽 조각이 하나씩 비어가요. 겉테두리는 끝까지 남아요.
• 체력 표시: 하트 자체가 변함. 피격 때마다 왼쪽 조각, 오른쪽 조각, 아래 조각 순으로 비워짐. 세 번째 피격에서 모두 비면 게임오버
• 피격 슬로우: 피격 순간 게임과 노래가 함께 느려졌다 돌아옴. 처음엔 약 0.4초였다가 더 강하게 조정해서 지금은 약 0.7초, 가장 느릴 때 0.3배. 노래 속도(pitch)도 같이 내려감
• 무적: 피격 후 약 1.5초 동안 추가 피격 없음. 이 동안 화면의 검정과 흰색이 반전되고, 움직이는 것 뒤로 잔상이 번지는 모션 블러가 걸림 (2D 렌더러는 URP 기본 모션 블러가 동작하지 않아서, 지난 화면을 섞는 렌더러 기능으로 직접 만듦)
• 값 조정: 슬로우 길이, 슬로우 정도, 무적 시간은 모두 설정값으로 빼서 직접 만져보며 맞춤
장애물 6종
장애물은 여섯 종류이고 (처음 계획한 네 종류 + 나중에 추가한 가시, 부메랑), 모두 한 가지 색과 단순한 도형으로 그려요. 색은 곡마다 바뀔 수 있어서 레벨 데이터에 넣어요.

장애물 디자인
발사체는 채운 도형, 발사기는 같은 모양의 속 빈 테두리로 해요. 한 가지 색만 쓰기 때문에 모양과 채움 여부로 구분하고, 발사기와 발사체의 짝이 한눈에 보이게 하려는 규칙이에요. 이 디자인은 시작안이고, 여유가 생기면 더 구체화해서 바꿀 수 있어요.

디자인 원칙은 이래요.
• 하트와 겹치지 않기: 마름모 모양은 쓰지 않고, 곡마다 색을 바꿀 때도 빨강 계열은 피함
• 경고는 같은 모양의 반투명판으로 해서 어디에 무엇이 오는지 알려줌
• 모든 등장, 발사, 소멸에 짧은 크기 변화와 페이드를 넣어 하트의 부드러운 이동과 느낌을 맞춤
• 충돌 판정은 보이는 모양보다 약간 작게 잡아 억울한 피격을 줄임
타이밍 기준과 레벨 데이터
모든 장애물의 시간은 노래의 재생 위치(초)를 기준으로 기록해요. 그래야 피격 슬로우로 게임과 노래가 함께 느려져도 장애물이 비트에서 어긋나지 않고, 에디터 미리보기와 실제 플레이가 똑같이 동작해요.
타이밍 기준 (확정): 에디터에서 찍는 시간은 위험이 실제로 발동하는 순간이에요. 포탄이 격자에 닿는 순간, 레이저가 켜지는 순간, 바닥 포탄이 튀어나오는 순간이에요. 발사 장치 등장과 경고는 그보다 앞서 자동으로 시작해요. 이렇게 하면 비트에 맞춰 "쾅" 하고 위험이 생겨서 리듬 게임답게 느껴져요.
레벨은 곡마다 JSON 파일 하나로 Assets/Levels에 저장해요. 곡 파일은 Assets/Audio에 두고 audioFile의 파일 이름으로 연결해요. (곡 파일은 저작권 때문에 git에 올리지 않고 팀원이 각자 넣어요)
레벨 데이터 형식 (단계 4에서 확정):
{
  "version": 1,
  "title": "곡 제목",
  "audioFile": "song.mp3",
  "bpm": 128,
  "offset": 0.0,
  "obstacleColor": "#ffffff",
  "obstacles": [
    { "type": "cannon", "time": 12.5, "side": "left", "line": 2 },
    { "type": "cannon", "time": 13.0, "side": "top", "line": 4, "speed": 12 },
    { "type": "laser", "time": 14.0, "axis": "row", "line": 3, "warnTime": 0.9, "holdTime": 0.4 },
    { "type": "floor", "time": 15.0, "cell": [1, 4], "warnTime": 0.9, "blockTime": 2.0 },
    { "type": "homing", "time": 16.0, "side": "top", "line": 0 },
    { "type": "spike", "time": 17.0, "side": "left", "line": 2, "warnTime": 0.6, "holdTime": 0.5 },
    { "type": "boomerang", "time": 18.0, "side": "right", "line": 1, "range": 3 }
  ]
}
• 시간은 항상 초 단위로 저장. BPM과 offset은 에디터가 박 단위 칸 맞춤을 돕는 용도이고 장애물 타이밍 계산에는 쓰지 않음
• version: 형식 버전. 지금은 1. 나중에 형식이 바뀌면 올려서 예전 파일과 구분
• 좌표: 칸 [x, y]는 (0, 0)이 왼쪽 아래. 줄 번호(line)는 0부터 시작
• side: 발사기가 자리 잡는 쪽(left, right, top, bottom). 발사체는 그 반대쪽으로 날아감
• line: side가 left/right면 가로줄 번호(0이 아래), top/bottom이면 세로줄 번호(0이 왼쪽). 레이저는 axis가 row면 가로줄, col이면 세로줄
• cannon의 time: 포탄의 중심이 격자 바깥 선에 닿는 순간
• speed (cannon, homing, 선택): 발사체 속도(칸/초). 적지 않으면 인스펙터의 기본값(일반 포탄 8칸/초). 유도탄은 발사 순간의 속도이고 그 뒤로 점점 빨라짐
• spike의 time: 가시가 튀어나오는 순간. side·line·warnTime·holdTime을 씀 (새 필드 없음)
• boomerang의 time: 부메랑이 처음 격자 바깥 선에 닿는 순간. range (선택): 격자 안으로 몇 번째 칸 가운데까지 갔다가 돌아오는지(칸 수, 적지 않으면 3). speed는 발사 순간 속도이고, 돌아올 때도 같은 속도로 발사 장치에 들어옴
• homing의 time: 유도탄이 발사되는 순간. 유도탄은 하트를 따라가서 닿는 시점이 플레이어 움직임에 따라 달라지므로, 다른 장애물과 달리 발사 순간을 기준으로 함
• warnTime, holdTime, blockTime (선택): 적지 않거나 0이면 인스펙터의 기본값(경고 0.9초, 레이저 유지 0.4초, 바닥 포탄 막기 2초)
• floor의 time: 바닥 포탄이 튀어나오는 순간. 이때 하트가 그 칸에 걸쳐 있으면 피격이고, 그 뒤 blockTime 동안 그 칸에 들어갈 수 없음. 같은 칸을 여러 바닥 포탄이 겹쳐 막으면 마지막 것이 풀릴 때까지 막힘
• 각 종류에서 쓰지 않는 필드는 적지 않아도 됨
• 시작안에서 바뀐 점: version과 speed를 추가하고, 좌표와 줄 번호 규칙을 정함. 나머지 필드 이름은 시작안 그대로
레벨 에디터는 유니티 에디터 안의 커스텀 창으로 만들어요.
• 곡 불러오기, BPM과 오프셋 입력
• 타임라인에서 장애물 추가, 이동, 삭제, 복사
• 배치 모드 두 가지: 1박·1/2박·1/4박에 맞춰 붙이는 모드, 초 단위로 자유롭게 놓는 모드
• 같은 장애물을 간격을 두고 반복 배치해서 연속 장애물을 빠르게 만드는 기능
• 곡을 재생하면서 배치를 미리 보는 기능 (재생, 정지, 위치 이동)
• JSON 저장과 불러오기
화면 구성
화면은 메뉴, 플레이, 일시정지, 클리어, 게임오버 다섯 가지예요. 디자인은 게임 본편과 같이 검은 배경에 한 가지 색의 단순한 글자와 도형으로 해요.
• 메뉴 (곡 선택): 곡은 1개지만 곡 목록 구조로 만들어 두면 나중에 곡을 늘리기 쉬움
• 플레이: 격자, 하트, 장애물, 노래
• 일시정지: 노래도 같이 멈춤. 계속하기, 다시 시작, 메뉴로 나가기
• 클리어: 노래 끝까지 살아남으면 표시. 다시 하기, 메뉴로
• 게임오버: 목숨이 모두 없어지면 표시. 다시 하기, 메뉴로
단계별 제작 순서
Claude에게 한 단계씩 지시하고, 유니티에서 실행해 확인한 뒤 다음 단계로 넘어가요. 위험하고 기반이 되는 것부터 만들어요. 일정은 1주차 단계 0~3, 2주차 단계 4~8, 3주차 단계 9~12예요.
매 단계 공통 방법
1. 이 설계서에서 해당 부분을 붙여넣고 지시문을 보냄
2. 지시문 끝에 '이번 단계만 만들고, 유니티 에디터에서 내가 할 조작을 순서대로 알려줘. 스크립트는 파일 이름과 함께 전체 코드로 줘.'를 덧붙임
3. 실행해서 각 단계의 확인 항목을 모두 통과하면 다음 단계로 감
4. 에러가 나면 콘솔의 빨간 메시지를 그대로 복사해서 Claude에게 보냄
5. 단계가 끝날 때마다 프로젝트 폴더를 통째로 복사해 백업함
단계 0. 준비
나는 유니티를 처음 써. Unity 6 LTS로 Universal 2D 프로젝트를 만드는 방법과, 스크립트를 만들어 오브젝트에 붙이는 기본 방법을 순서대로 알려줘. 프로젝트 폴더는 Scripts, Levels, Audio, Prefabs로 나눌 거야.
• 확인: 빈 2D 씬이 열리고, 테스트 스크립트가 콘솔에 글자를 출력함
단계 1. 격자와 하트 이동
검은 배경에 5x5 격자를 흰 선으로만 그려줘. 칸 크기는 설정값으로 빼줘. 빨간 하트(우선 정사각형이어도 돼)를 만들고 WASD와 방향키로 키 한 번에 한 칸씩 이동하게 해줘. 격자 밖으로는 못 나가. 이동은 목표 칸까지 남은 거리의 일정 비율씩 다가가는 방식이고, 프레임 속도와 상관없이 같은 속도여야 해. 비율은 인스펙터에서 조절할 수 있게 해줘. 이동 중에는 잔상이 남았다가 흐려지게 해줘.
• 확인: 8개 키 모두 한 칸 이동, 가장자리에서 멈춤, 비율을 바꾸면 속도가 바뀜, 잔상이 보임
단계 2. 하트 모양과 체력 표시
하트를 도형 조각으로 만들어줘. 45도 기울인 정사각형을 2x2로 나눈 조각 중 위쪽을 뺀 모양이야. 겉테두리는 항상 보이고, 안쪽 채움 조각은 왼쪽, 오른쪽, 아래 3개야. 테스트용으로 H 키를 누를 때마다 왼쪽, 오른쪽, 아래 순서로 채움이 비워지게 해줘. 하트가 빛나 보이게 Bloom도 설정해줘.
• 확인: H를 세 번 누르면 순서대로 비워지고 테두리는 남음, 하트가 빛남
단계 3. 노래 시계와 슬로우
노래 파일 하나를 재생하고, 노래의 재생 위치(초)를 게임의 기준 시계로 쓰는 구조를 만들어줘. 테스트로 BPM을 넣으면 박마다 화면이 깜빡이게 해줘. 테스트 키를 누르면 게임과 노래가 함께 잠깐 느려졌다가 돌아오게 해줘(노래 pitch도 같이). 이후 모든 장애물 타이밍은 이 시계를 기준으로 할 거야.
• 확인: 깜빡임이 박자와 맞음, 느려졌다 돌아온 뒤에도 박자가 어긋나지 않음
단계 4. 레벨 데이터와 일반 포탄
(설계서의 '타이밍 기준과 레벨 데이터' 부분을 붙여넣기)
JSON 레벨을 읽어서 각 장애물을 time에 맞춰 만들어주는 스포너를 만들어줘. 먼저 일반 포탄(cannon)만 구현해줘. 발사 장치가 화면 밖에서 와서 격자 가장자리의 지정한 줄 근처에 자리 잡고, 포탄이 time에 격자에 닿도록 격자 줄을 따라 직선으로 날아가게 해줘. 대각선은 없어. 포탄이 하트에 닿으면 콘솔에 '피격'을 출력해줘. 충돌은 하트 크기 기준이고 이동 중에도 판정해. 테스트용 레벨 JSON도 만들어줘. JSON 필드 이름은 더 좋은 안이 있으면 제안해줘.
• 확인: 박자에 맞춰 포탄이 격자에 닿음, 4방향 모두 동작, 닿으면 '피격'이 출력됨
• 이 단계에서 JSON 필드 이름을 확정하고, 설계서를 갱신함
단계 5. 레이저
레이저(laser)를 추가해줘. 가로 또는 세로 한 줄(1칸 두께)이 time에 발동하고 holdTime 동안 유지돼. 발동 전 warnTime 동안 그 줄에 반투명 경고가 표시돼야 해. 여러 줄을 같은 time에 동시에 발동할 수 있어야 해. 발동 중인 줄 위에 하트가 있으면 '피격'을 출력해줘.
• 확인: 경고가 반투명하게 보이다가 발동, 발동 중에만 피격, 동시 다발 가능
단계 6. 바닥 포탄과 막힌 칸
바닥 포탄(floor)을 추가해줘. 지정한 칸이 warnTime 동안 반투명 경고를 보이고, time에 그 칸에서 포탄이 아래에서 튀어나와. 튀어나올 때 하트가 그 칸에 있으면 '피격'이야. 이후 blockTime 동안 그 칸은 막힌 칸이 돼서 하트가 들어갈 수 없어. 막힌 칸으로 가려고 해도 피해는 없어. 막힌 시간이 지나면 다시 갈 수 있어.
• 확인: 튀어나올 때 서 있으면 피격, 막힌 동안 이동 불가이며 피해 없음, 시간이 지나면 해제됨
단계 7. 유도탄
유도탄(homing)을 추가해줘. 발사 장치가 화면 밖에서 지정한 줄 위치로 와서 자리 잡고, time에 발사돼. 발사 후 하트를 따라가는데 속도는 점점 빨라지고 방향을 바꾸는 능력은 점점 낮아져서 결국 피할 수 있어야 해. 화면 밖으로 나가면 터지는 모션과 함께 사라져. 하트에 닿으면 '피격'을 출력하고 터지며 사라져. 속도 증가량과 방향 전환 감소량은 설정값으로 빼줘.
• 확인: 처음엔 잘 따라오다 점점 못 꺾음, 피할 수 있음, 화면 밖에서 터지는 모션 후 사라짐
단계 8. 피격 연출
'피격' 출력 대신 실제 피격 처리를 만들어줘. 피격 시 하트 조각이 왼쪽, 오른쪽, 아래 순으로 비워져. 피격 순간 게임과 노래가 약 0.4초 느려졌다 돌아오고, 이후 약 1.5초 동안 무적이야. 무적 동안 화면의 검정과 흰색이 반전돼. 세 번째 피격에서는 게임오버 신호를 보내줘. 슬로우 길이, 슬로우 정도, 무적 시간은 설정값으로 빼줘.
• 확인: 맞을 때 슬로우가 느껴짐, 무적 중 추가 피격 없음, 화면 반전, 3번째에 게임오버 신호
단계 9. 레벨 에디터 기본
유니티 에디터 안의 커스텀 창(EditorWindow)으로 레벨 에디터를 만들어줘. 곡 파일을 불러오고 BPM과 오프셋을 입력할 수 있어야 해. 타임라인에서 장애물 6종(가시, 부메랑 포함)을 추가, 이동, 삭제, 복사할 수 있어야 해. 배치는 1박, 1/2박, 1/4박에 맞춰 붙는 모드와 초 단위로 자유롭게 놓는 모드를 둘 다 지원해줘. 발사 장치와 유도탄의 출발 위치는 칸에 맞춰 고르게 해줘. 결과는 우리 JSON 형식으로 저장하고 다시 불러올 수 있게 해줘.
• 확인: 장애물을 배치해 저장한 JSON이 단계 4의 스포너에서 그대로 재생됨, 저장 후 다시 불러와도 같음
단계 10. 에디터 미리보기와 반복 배치
에디터에서 곡을 재생하면서 장애물이 나오는 모습을 바로 미리 볼 수 있게 해줘. 재생, 정지, 원하는 위치로 이동이 돼야 해. 그리고 선택한 장애물을 간격(박 또는 초)을 정해 N번 반복 배치하는 기능을 만들어줘. 연속으로 날아오는 장애물을 빨리 만들기 위해서야.
• 확인: 미리보기가 실제 플레이와 같은 타이밍으로 나옴, 반복 배치가 정확한 간격으로 생김
단계 11. 화면 구성
메뉴(곡 선택), 일시정지, 클리어, 게임오버 화면을 만들어줘. 디자인은 검은 배경에 한 가지 색의 단순한 글자와 도형으로 해줘. 곡 선택은 곡 목록 구조로 하고, 일시정지에서는 노래도 같이 멈춰야 해. 클리어는 노래 끝까지 살아남았을 때, 게임오버는 목숨이 모두 없어졌을 때 떠. 두 화면 모두 다시 하기와 메뉴로 가기가 있어야 해.
• 확인: 메뉴에서 시작해 플레이, 일시정지, 클리어와 게임오버까지 한 바퀴가 끊김 없이 돌아감
단계 12. 곡 제작과 다듬기
(플레이해 보고 불편한 점을 적어서 보내기) 이동 비율, 잔상, 슬로우, 무적, 경고 시간 같은 값들을 한 곳에서 조절할 수 있게 모아줘. 그리고 내가 말한 불편한 점을 고쳐줘.
• 확인: 에디터로 곡 1개의 레벨을 끝까지 만들고, 처음부터 끝까지 플레이해서 클리어가 가능함
3명이 한 컴퓨터로 진행할 때 (제안): 한 명은 Claude에게 지시하고, 한 명은 확인 항목을 체크하고, 한 명은 곡의 패턴을 구상해요. 단계마다 역할을 돌아가며 맡으면 모두 전체 구조를 이해할 수 있어요.
여유가 생기면: 레벨 자동 생성
곡에서 비트를 찾아 장애물 하나(일반 포탄)만으로 레벨을 자동으로 채우는 기능이에요. 단계 12까지 끝난 뒤에 도전하는 확장 기능이에요.
• 결과물: 기존과 같은 JSON 레벨 파일. 그래서 에디터에서 열어 손으로 고치거나 다른 장애물을 더할 수 있음
• 쉬운 방식: BPM과 오프셋을 입력하면 박마다 포탄을 배치. 줄 번호는 규칙이나 무작위로 정함
• 어려운 방식: 곡의 소리를 분석해 실제로 강하게 울리는 순간(드럼, 강세)을 찾아서 거기에 배치. 같은 BPM의 곡도 곡마다 다르게 나옴
• 에디터에 '자동 생성' 버튼으로 붙이고, 난이도(배치 밀도)를 설정값으로 둠
• 순서 제안: 쉬운 방식을 먼저 만들고, 되면 어려운 방식으로 확장
레벨 에디터에 '자동 생성' 기능을 추가해줘. 먼저 쉬운 방식으로, 입력한 BPM과 오프셋을 기준으로 박마다 일반 포탄을 배치해줘. 줄 번호는 같은 줄이 연속으로 너무 반복되지 않게 정해줘. 배치 밀도(몇 박마다 하나)는 설정값으로 빼줘. 결과는 우리 JSON 형식으로 만들어서 에디터에서 바로 수정할 수 있게 해줘.
• 확인: 생성된 레벨이 박자에 맞게 재생되고, 에디터에서 열어 수정할 수 있음
아직 정하지 않은 것
