# Game01 — 리듬 회피 게임

검은 화면의 5×5 격자 안에서, 노래의 비트에 맞춰 날아오는 장애물을 피해 곡 끝까지 살아남는 2D 리듬 회피 게임입니다.
한 가지 색과 단순한 도형, 부드러운 움직임을 목표로 합니다.

전체 설계는 [docs/design.md](docs/design.md)에 있습니다.

## 현재 진행 상황

설계서의 단계별 제작 순서 중 **단계 1~2**까지 진행했습니다.

| 기능 | 상태 |
|---|---|
| 검은 배경, 흰 선으로 그린 5×5 격자 | 완료 |
| WASD·방향키로 한 칸씩 이동, 격자 밖으로 못 나감 | 완료 |
| 목표 칸까지 남은 거리의 일정 비율씩 다가가는 부드러운 이동 (프레임 속도와 무관) | 완료 |
| 이동 중 뒤로 갈수록 가늘고 흐려지는 꼬리 잔상 | 완료 |
| 픽셀 하트 이미지 플레이어, Bloom으로 빛나는 효과 | 완료 |
| 화면 왼쪽 위 HP 하트 3개 (테스트 키로 하나씩 줄어듦) | 완료 |
| 노래 시계와 슬로우 (단계 3) | 예정 |
| 레벨 JSON과 장애물 4종 (단계 4~7) | 예정 |
| 피격 연출 (단계 8) | 예정 |
| 레벨 에디터 (단계 9~10) | 예정 |
| 메뉴, 일시정지, 클리어, 게임오버 화면 (단계 11) | 예정 |

> 설계서와 달라진 점: 처음 계획은 하트 조각이 하나씩 비는 방식으로 체력을 보여 주는 것이었지만, 지금은 하트 이미지를 쓰고 체력은 화면 왼쪽 위의 하트 아이콘으로 보여 줍니다.

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 한 칸 이동 |
| `H` | (테스트용) 피격 — HP 하나 감소 |

## 개발 환경

- Unity **6000.6.6f1** (Unity 6), Universal 2D 템플릿
- Universal Render Pipeline (2D Renderer), Bloom 후처리 사용
- Input System 패키지 (새 입력 시스템만 사용)

## 프로젝트 여는 법

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/seojin715/Game01.git
   ```
2. Unity Hub → **Add** → 내려받은 폴더를 선택합니다. 위와 같은 유니티 버전으로 여는 것을 권장합니다.
3. 처음 열 때는 유니티가 `Library` 폴더를 새로 만드느라 몇 분 걸립니다.
4. `Assets/Scenes/SampleScene` 을 열고 ▶ 를 누릅니다.

## 함께 작업할 때 지킬 것

- **같은 유니티 버전(6000.6.6f1)으로 여세요.** 다른 버전으로 열면 설정 파일이 바뀌어 다른 사람과 충돌이 납니다.
- **`.meta` 파일은 항상 원래 파일과 같이 커밋하세요.** `.meta` 가 빠지면 다른 컴퓨터에서 인스펙터 연결(이미지, 스크립트 참조)이 끊깁니다.
- **같은 씬을 두 사람이 동시에 고치지 마세요.** 씬 파일은 자동으로 합쳐지지 않아서 한쪽 작업이 사라질 수 있습니다.
- 작업 전에 `git pull` 로 최신 상태를 받고, 끝나면 유니티에서 `Ctrl + S` 로 씬을 저장한 뒤 커밋하세요.
- `Library`, `Temp`, `Logs` 같은 폴더는 올리지 않습니다 (`.gitignore` 에 들어 있음). 유니티가 열 때 다시 만듭니다.
- 빈 폴더 안의 `.gitkeep` 은 git이 빈 폴더를 저장하지 않아서 넣어 둔 파일입니다. 그 폴더에 다른 파일이 생기면 지워도 됩니다.

## 스크립트

| 파일 | 역할 |
|---|---|
| `GameGrid.cs` | 격자 크기, 칸 좌표 ↔ 월드 좌표 변환, 카메라 자동 맞춤 |
| `GridView.cs` | 격자를 흰 선으로만 그림 |
| `PlayerMover.cs` | 키 입력과 칸 단위 이동 |
| `HeartView.cs` | 하트 이미지 표시, 크기와 발광 |
| `PlayerTrail.cs` | 이동 꼬리 잔상 |
| `PlayerHealth.cs` | 목숨 관리 (지금은 `H` 키로 테스트) |
| `HealthDisplay.cs` | 화면 왼쪽 위 HP 아이콘 |
| `SpriteMaterial.cs` | 발광 머티리얼과 크기 맞춤 공용 도구 |
| `ShapeSprites.cs` | 코드로 만드는 단순 도형 스프라이트 |

조절할 만한 값(이동 비율, 칸 크기, 잔상 길이, 발광 세기 등)은 코드에 박지 않고 인스펙터에서 바꿀 수 있게 해 두었습니다.

## 설계 원칙

- **모든 장애물 타이밍은 노래의 재생 위치(초)를 기준으로 합니다.** 피격 슬로우로 게임과 노래가 느려져도 장애물이 비트에서 어긋나지 않게 하기 위해서입니다.
- 레벨 데이터의 `time` 은 "위험이 실제로 닿는 순간"이고, 발사기 등장과 경고는 그보다 앞서 자동으로 시작합니다.
- 화면은 검은 배경에 한 가지 색과 단순한 도형만 사용합니다.
